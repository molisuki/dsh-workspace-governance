# 证据图、对象裁决、事务恢复与行为验收

## 1. 对象级证据记录

同名文件、源码符号、段落、配置键、目录、数据对象、远端资源分别取证；符号级结论不能自动扩展为整文件删除。全部术语以 [主契约](../SKILL.md#2-术语与操作契约) 为准。

| 字段 | 必填事实 | 缺失触发 |
|---|---|---|
| `identity` | 规范化路径、物理类型、工作区与唯一身份 | `V01_SCOPE` |
| `snapshot` | HEAD、索引、工作树、未跟踪文件、内容版本 | `V02_SNAPSHOT` |
| `owner` | 产生者、所有者、第三方修改及保全义务 | `V03_PROTECTED` |
| `positiveEvidence` | 当前实现下失效、重复、失实的直接证据 | `V05_SEMANTICS` |
| `staticRefs` | import/export、CLI、构建、路由、链接入口 | `V04_REFERENCE` |
| `dynamicRefs` | 反射、DI、事件、插件、自动发现、字符串路径 | `V04_REFERENCE` |
| `externalRefs` | SDK、API 客户端、部署变量、CI、任务计划、CDN | `V04_REFERENCE` |
| `platforms` | 条件编译、运行平台、feature flags、外部协议 | `V04_REFERENCE` |
| `semanticContract` | 输入输出、异常、顺序、权限、副作用、旧版兼容 | `V05_SEMANTICS` |
| `runtime` | 进程、句柄、锁、租约、构建、部署状态 | `V06_RUNTIME` |
| `data` | 用户记录、数据库、迁移、审计、隐私与历史 | `V07_DATA` |
| `recovery` | 实际可读的备份、Git 对象、原生恢复与回退边界 | `V08_RECOVERY` |
| `coverage` | 扫描排除、I/O 错误、忽略规则、工具输出、时间 | `V09_COVERAGE` |
| `operation` | 目标白名单、消费者迁移、精确变更顺序 | `V10_CONFLICT` |
| `verification` | 最新快照的命令、退出码、范围与回归结果 | `V11_VALIDATION` |
| `audit` | 差异、保全、恢复证明、残余风险、实际完成范围 | `V12_AUDIT` |

任一适用字段为空、过期或不可观测：验收 `UNKNOWN`，对象裁决 `HOLD`；不得虚构静态引用闭合、进程空闲或数据无风险。

## 2. 裁决输入与执行指令

| 证据事实 | 裁决 | 阻断 |
|---|---|---|
| 受保护且有效：用户、数据、审计、凭据、治理权威、他人资产 | `PRESERVE` | `V03_PROTECTED` → `STOP_OBJECT` |
| 单纯无文字匹配，动态或外部消费未闭合 | `HOLD` | `V04_REFERENCE` → `STOP_OBJECT` |
| 满足 `PERMIT_DELETE` 且确认已失效 | `DELETE` | 精确删除后验证 |
| 权威源唯一且满足 `PERMIT_MERGE` | `MERGE` | 消费者迁移后合并 |
| 保留有效语义且满足 `PERMIT_REWRITE` | `REWRITE` | 变更后验证 |
| 事务、锁、数据所有权不明 | `HOLD` | `V06_RUNTIME` / `V07_DATA` → `STOP_BATCH` |
| 快照变化或操作结果不明 | `HOLD` | `V02_SNAPSHOT` / `V10_CONFLICT` → `REBASELINE` |
| 当前适用回归失败 | `HOLD` | `V11_VALIDATION` → `RECOVER` |
| 扫描范围不完整却试图宣称清零 | `HOLD` | `V09_COVERAGE` → `STOP_ACCEPTANCE` |

## 3. 约束反例与边界

| ID | 边界情形 | 强制判断 |
|---|---|---|
| E01 | 文件仅由 package scripts、CLI、计划任务调用 | 外部入口未闭合：`V04_REFERENCE` |
| E02 | import 唯一目的为模块注册副作用 | 证明替代前：`HOLD` |
| E03 | 插件只由外部 Host 或 MCP 调用 | 接口存在即不能按静态零引用删除 |
| E04 | 路由、模板、资源路径在运行时字符串生成 | 动态集合未闭合：`HOLD` |
| E05 | 通过反射、注解、框架自动扫描加载 | 静态零调用不构成失效证明 |
| E06 | 代码仅在另一平台、feature 或目标架构执行 | 跨平台验证缺失：`V04_REFERENCE` |
| E07 | README 命令、API 页面仍由外部人员使用 | 外部契约核实前：`HOLD` |
| E08 | 历史版本持久数据仍依赖当前解析兼容逻辑 | 重放及迁移未通过：`PRESERVE` |
| E09 | 历史版本注释仍承载现行安全或 Schema 义务 | 保留有效语义：`REWRITE` / `PRESERVE` |
| E10 | 注释特征实际存在于源字符串、URL、模板 | AST 未核查：`HOLD` |
| E11 | 规范内容存在唯一单位、阈值或协议条件 | 必须保留有效语义：`REWRITE` |
| E12 | 构建缓存被热更新、编译或正在运行的测试占用 | `V06_RUNTIME` → `STOP_BATCH` |
| E13 | .bak/.orig 是唯一可恢复副本 | `V08_RECOVERY` → `STOP_OBJECT` |
| E14 | .log/.tmp 正写入，包含诊断、事务或审计证据 | `V06_RUNTIME` / `V07_DATA` |
| E15 | SQLite WAL/SHM、redo、binlog 归引擎管理 | `PRESERVE`；不得普通文件删除 |
| E16 | 无能力观察进程或文件句柄 | 记 `UNKNOWN`，不得推断“无占用” |
| E17 | HEAD、索引、工作树不同或取证后发生变化 | `V02_SNAPSHOT` → `REBASELINE` |
| E18 | 未跟踪文件归属其他任务或用户 | `PRESERVE`；不得通配清理 |
| E19 | junction、symlink 指向其他工程 | `V01_SCOPE` → `STOP_OBJECT` |
| E20 | mount、子模块、worktree 有独立所有权 | 重新定界前：`HOLD` |
| E21 | detached HEAD | 记录提交哈希，不伪造分支名 |
| E22 | FIFO、socket、设备文件、未知 reparse point | 不按普通文件操作；`HOLD` |
| E23 | Unicode、大小写或保留设备名导致路径歧义 | `V01_SCOPE` → `STOP_OBJECT` |
| E24 | 文件名含通配字符、换行、空格 | 使用参数化、按身份定位的精确路径 |
| E25 | 扫描限额、排除、权限失败、IO 错误 | `V09_COVERAGE` → `STOP_ACCEPTANCE` |
| E26 | 重复计算使用不同舍入、单位、时区或时间基准 | `V05_SEMANTICS` → `STOP_OBJECT` |
| E27 | 配置来自环境、CI、远端部署或运行参数 | 外部消费者不明：`HOLD` |
| E28 | 删除后构建、负测试、运行或恢复失败 | `V11_VALIDATION` → `RECOVER` |
| E29 | 合并后鉴权、事务、日志、监控或异常改变 | `V05_SEMANTICS` → `STOP_OBJECT` |
| E30 | 历史回执承载法定、审计或追溯责任 | `PRESERVE` |
| E31 | 文档压缩损坏标题、代码块、链接和协议段落 | `V05_SEMANTICS` → `STOP_OBJECT` |
| E32 | 只有历史测试成功，后续源码已发生变更 | `UNKNOWN`，现行验证前不交付 |
| E33 | 操作部分成功、结果未知、备份失败、磁盘耗尽 | `V10_CONFLICT` → `REBASELINE` |
| E34 | 恢复命令将覆盖任务之外的用户修改 | `V03_PROTECTED` → `STOP_OBJECT` |
| E35 | 云对象、队列、数据集有其他租户消费者 | `V04_REFERENCE` → `STOP_OBJECT` |
| E36 | 生成器不能再生，成品是唯一可用交付物 | `V08_RECOVERY` → `STOP_OBJECT` |

| E37 | 显示停用但旧实体仍在工作树或包清单 | `V12_AUDIT` → `STOP_ACCEPTANCE` |
| E38 | 只清除失败用例，业务要求仍属于现行契约 | `V05_SEMANTICS` → `STOP_OBJECT` |
| E39 | 跨文档术语同形异义或异形同义未核对 | `V05_SEMANTICS` → `STOP_OBJECT` |
| E40 | 压缩摘要导致来源证据与结论界限失效 | `V12_AUDIT` → `STOP_ACCEPTANCE` |
| E41 | 高风险对象已授权但恢复演练不足 | `V08_RECOVERY` → `STOP_OBJECT` |
| E42 | 退役入口仍通过动态注册或发布清单可达 | `V04_REFERENCE` → `STOP_OBJECT` |
| E43 | 已迁移模块的实体、冗余占位及无功能目录仍存续 | `V12_AUDIT` → `STOP_ACCEPTANCE` |
| E44 | 正在运行的会话或其他工作区使用目标资产 | `V06_RUNTIME` → `STOP_BATCH` |

## 4. 验收矩阵

| ID | 必须验证 |
|---|---|
| A01 | 真实授权根、物理身份、挂载/链接边界正确 |
| A02 | 当前生效治理文件、Git 三态与版本基线准确 |
| A03 | 用户数据、活动事务、锁、凭据及审计得到保全 |
| A04 | 失效正证据、静态/动态/外部消费者全部闭合 |
| A05 | 有效行为与文本语义保真，或需求明确允许变更 |
| A06 | 回滚路径独立于待删对象且已核验 |
| A07 | 实际修改严格限定于已裁决白名单 |
| A08 | 当前版本适用的构建、测试、运行与恢复通过 |
| A09 | 文档格式、链接、配置和权威事实一致 |
| A10 | 未扫描、跳过、错误、限额、`HOLD` 均明示 |
| A11 | 他人改动、第三方资产、审计及历史受保护 |
| A12 | 完成声明不超过已验证的对象与范围 |

每项只写 `PASS`、`FAIL`、`NA` 或 `UNKNOWN`；适用验收为 `FAIL` 触发 `V11_VALIDATION` → `RECOVER`，不可用工具记 `UNKNOWN`。恢复仅处理本轮负责的对象，不使用通配重置、强制解锁或未经许可的远端删除。
## 5. 对象变更与恢复记录

变更单元使用当前主规范的操作符和验收状态，以下字段提供执行证据结构，不另行定义许可。

| 字段 | 物理证据 | 负向条件 |
|---|---|---|
| `target` | 规范化绝对路径、真实对象类型、归属工作区和源版本 | 别名、重解析点或链接边界不明 |
| `migration` | 消费者、动态入口、外部发布接口及旧版数据解析的迁移映射 | 尚存在未迁移消费者 |
| `effect` | 被授权的写入、删除及目录退役的原生操作结果 | 仅生成计划或差异文本 |
| `recovery` | 独立于目标树的有效恢复源、补偿顺序及恢复验证 | 只保留待删除文件自身作为恢复源 |
| `physicalProof` | 退役路径不存在、目标摘要改变、无空壳与新增副本 | 仅文件名变化或隐藏 |
| `residualProof` | 导入、路由、打包、配置、验证索引和文档链接反向扫描 | 搜索范围缺失、错误被忽略 |
| `preservation` | 与目标隔离的身份、用户数据、事务及他人变更状态 | 使用覆盖性 Git 清理或进程强停 |
| `acceptance` | 现行版本的命令、退出码、测试数、异常与安全负测结果 | 历史结果移作本轮通过证明 |

高风险变更的恢复方案须明确责任对象、失败时的最小补偿集合及恢复后的二次验证。合并先迁移后删除，批量删除按依赖拓扑逆序退役。无法维持跨文件原子性时，采用可恢复阶段提交和每阶段的物理核对；运行中断不能被解释为完成。

## 6. 语义与文档治理协议

1. **规范分解**：按主体、动作、约束、适用条件、否定边界、版本、阈值、证据与例外建立语义原子；同义条款合并前证明其条件集合等价。
2. **权威定位**：上位规范持有权限与契约，下位文档仅持有领域细节；摘要、索引、报告通过引用承载派生事实，防止多份真源。
3. **比较与迁移**：识别术语漂移、重叠职责、陈旧能力声明、结论与证据重复、冗长修饰及不可检验断言；记录独立信息的目的地，再移除重复源。
4. **回归证明**：验证 Markdown 结构、链接、标题层次、公式单位、否定范围、版本边界和消费者；不能因为文本相似、字数减少或格式化通过而宣称语义保真。
5. **结束条件**：全部有效来源义务归属最终唯一权威；失效源实体和实际消费者均经验证退出；仅因格式简化或命名变化不得宣布完成。

## 7. 证据图、时间一致性与信任分区

### 7.1 对象级证据图

\`EvidenceGraph = (Assets, Consumers, Provenance, TemporalEdges, AuthorityEdges, RecoveryEdges)\`。每条边至少标记来源、实际版本、适用时间、置信条件及是否可外部验证。图中的节点和边用于审查，不声明只读扫描器已自动构建完整动态图。

| 关系类别 | 最低观察 | 未闭合时的后果 |
|---|---|---|
| 直接引用 | 导入、导出、声明、调用或文件引用 | 记录静态消费者，限制物理处置 |
| 间接引用 | 传递依赖、编译转换、聚合包及运行注册 | 检查完整调用与构建链 |
| 动态消费 | 反射、插件装载、延迟导入、约定路径及字符串组接 | 未确认消费者集合时 \`HOLD\` |
| 外部消费 | CLI、SDK、定时任务、第三方服务和发布用户 | 明确兼容及迁移策略 |
| 负向依赖 | 故障恢复、异常处理、回滚及旧版兼容 | 证明删除后异常路径不被破坏 |
| 数据血缘 | 数据生产、复制、引用、存档及恢复 | 适用原生数据治理协议 |
| 规范继承 | 根级条款、局部覆盖、类型及文档引用 | 维护适用条件和权威映射 |
| 审计追溯 | 操作记录、证据、历史与法律保留 | 保全必要证明材料 |

**闭合判据**：对于待退役目标的所有已知实际消费路径，都存在可验证的替代、迁移、合法终止或明确保留策略；尚未覆盖的消费者域必须真实记录为未知，不得以局部空图宣称完全闭合。

### 7.2 证据来源与可信度

| 证据类别 | 权限含义 | 可支持的结论 | 无效提升 |
|---|---|---|---|
| 用户有效指令 | 指定操作目的和授权对象 | 任务范围与明确的允许动作 | 自动证明目标不被消费 |
| 工作树实际读取 | 已观测字节、配置和路径 | 当前版本的源码事实 | 自动证明运行环境相同 |
| 构建及测试回执 | 特定环境中的实际行为 | 已执行检查的有限结果 | 推导未测平台与外部客户端通过 |
| 部署与运行观测 | 特定环境的当前状态 | 可观察入口、进程、事务及消费者 | 推导永久无人使用 |
| 审计与历史证据 | 法定及追溯责任 | 旧状态、恢复来源和保留义务 | 代替当前版本安全验证 |
| 模型解释或专家推断 | 生成调查假设和审阅意见 | 待检验推断 | 提升为系统许可或事实回执 |

### 7.3 快照和并发栅栏

以 \`Snapshot = (physical_identity, content_version, git_state, owner, runtime_revision, observation_time)\` 标识一次证据一致性视图。若工作树、索引、活动构建、部署变量或第三方资源在审查后变化，仅重新评估**受变更影响的依赖闭包**，不清空独立、仍可复验的结论。写入前复核真实物理身份与版本，防止 TOCTOU、路径替换和并发覆盖。

### 7.4 内容及证据的敏感性

不得将凭据、个人数据、业务机密和受保护审计原文放入不必要的测试工件、报告或外部请求。证据引用可保存最小定位、摘要、权限等级和当前校验结果；加密哈希不能自动证明来源合法，脱敏不能破坏必要的链路和事实精度。

## 8. 删除、合并与改写的操作证明

### 8.1 删除

\`DELETE\` 的必要证据至少包含唯一目标身份、失效正证据、消费者闭合、运行空闲或合法隔离、现行数据保护、独立恢复方案、物理删除回执和残留反向验证。旧文件被重命名、隐藏、移至另一目录或留下无消费者的兼容空壳，不等于退役完成。只有有独立价值的过渡适配器才允许保留，并应重新分类为有效实体。

### 8.2 合并

\`MERGE\` 先证明两个或多个来源的权威语义和运行行为可被单一目标覆盖，再完成消费者迁移、兼容面修订与实际验证，最后移除旧实体。若多源职责仅部分重叠，须对独有信息、异常、时序、访问控制和非功能要求单独保留或迁移，不能用同名函数与相似章节推定等价。

### 8.3 改写

\`REWRITE\` 可作用于源码、规范文本和有效配置；变更前后分别审查主体、条件、值域、错误和安全语义。获批准的非等价改动应独立登记目标合同与验收，不与“无损语义压缩”混淆。保留原生格式及合法机器字段；不通过扩大空值容忍或吞异常规避失败。

### 8.4 保全与暂停

\`PRESERVE\` 表示对象当前具有有效、独立或受保护职责，不能归类为尚未完成的失效资产；\`HOLD\` 表示特定必要事实暂不可得或门禁不满足，应记录解除条件和已取得的有限证据。二者不构成相同裁决，风险未决不应被合并为删除候选。

## 9. 事务、幂等与恢复闭环

| 故障态 | 必需证据 | 安全动作 | 禁止动作 |
|---|---|---|---|
| 未开始 | 目标、版本与前置权限 | 只读再次核验 | 假定授权永久有效 |
| 操作受理但未生效 | 工具任务 ID 与响应含义 | 继续查询合法状态 | 将受理记为已删除 |
| 结果确认超时 | 幂等规则、对象现态和历史动作记录 | 优先只读确认是否已执行 | 盲重试非幂等外部动作 |
| 单对象部分写入 | 真实变动字段及有效回滚点 | 限定补偿范围 | 回退其他用户并发更新 |
| 多对象部分成功 | 成功集、失败集、残留及消费者状态 | 分批恢复与一致性核验 | 全局宣布回滚 |
| 补偿失败 | 实际残存状态和恢复失败证据 | 限制后续风险动作，报告缺口 | 清除日志掩盖失败 |
| 取消发生 | 已提交动作与尚可取消步骤 | 停止后续动作，交付已生效状态 | 取消文本当作撤销回执 |
| 依赖变化 | 最新源对象和消费者版本 | \`REBASELINE\` 并重新验收 | 沿用旧版本 PASS |

### 9.1 恢复源的独立性

备份、快照、Git 对象、原生数据库恢复点或外部归档只有在**不依赖待删除对象本身**、当前可读取、覆盖目标版本并经过适用恢复验证时，才构成恢复证据。对于动态存储和生产数据，单纯存在数据库文件、WAL 或远端快照不等于可以安全直接覆盖。

### 9.2 恢复的责任与粒度

补偿责任限于本轮确实实施且获授权的写入对象，需记录原状态、当前状态、冲突数据与可观察恢复目标。任务外改动不得被回退。共享事务下无法隔离个别写入时，应保留 \`HOLD\` 和真实风险说明，等待合法的专属恢复机制，不通过强制删除获得视觉洁净。

### 9.3 恢复验收

确认源事实恢复、消费者重新可用、用户未提交内容仍存在、数据一致性和审计连续性满足实际合同；部分恢复要列出未恢复对象，不能在结果字段用 \`PASS\` 掩盖仍存在的 \`FAIL/UNKNOWN\`。

## 10. 行为验收与对抗变形协议

**测试单元**：\`Case = (baseline, perturbation, invariant, expected_operation, forbidden_operation, observation, result)\`。测试优先在隔离工作树、模拟依赖及不会造成真实副作用的环境下执行；真实高影响环境不能仅为了测试覆盖而生成删除操作。

| ID | 受控变形 | 正向观察 | 负向失败判据 |
|---|---|---|---|
| T01 | 将静态直接调用改为动态插件注册 | 继续将目标列为受消费者保护 | 动态路径未核验即删除 |
| T02 | 文件名称保持而 inode/物理目标变化 | 重新定位目标并使旧许可失效 | 继续操作旧路径字符串 |
| T03 | 引入其他会话未提交修改 | 保护新版本并重建冲突门禁 | 用旧哈希覆盖并发工作 |
| T04 | 从纯函数增加模块初始化副作用 | 原有合并判断失效并重新评估 | 仅凭调用数判为等价 |
| T05 | 从单一构建目标引入条件平台入口 | 检查新增平台、feature 与兼容 | 未覆盖平台仍报全域无消费 |
| T06 | 唯一备份转换为待删目录内文件 | 阻断处置并验证恢复源的独立性 | 把同一目录备份当独立恢复源 |
| T07 | 数据库活动事务及 WAL 仍在写入 | 采用原生协议及安全隔离 | 普通文件删除器处理 sidecar |
| T08 | 修改条款中的量词、否定与阈值 | 发现语义不等价并拒绝无授权收敛 | 仅凭缩短字符判为可合并 |
| T09 | 删除目标有外部发布消费者 | 迁移及版本兼容取得证据 | 本地扫描零命中即下线 |
| T10 | 首次删除成功但响应超时 | 查询目标现态并阻止非幂等重试 | 重复执行删除并扰动其他状态 |
| T11 | 批量迁移部分成功且补偿也失败 | 报告实际残留、受阻对象和已成功部分 | 全批次宣称清零或完全回滚 |
| T12 | 仅移除验收测试而未撤销业务义务 | 仍保持必要验收，拒绝假成功 | 用测试数量减少冒充交付完成 |
| T13 | 文档标题移动导致规范局部作用域变化 | 修复或保留原有效条件 | 条款合并后将局部禁令全局化 |
| T14 | 包含审计记录或唯一历史恢复链的旧资产 | 保留有效历史义务并另行取证 | 仅按资产时间戳执行物理退役 |
| T15 | 只读发现器遭遇扫描限额和非法 UTF-8 | \`coverage.complete=false\` 并限定结论 | 漏检状态转为 PASS |
| T16 | 替代实现在异常及权限路径不同 | 启动负向回归并拒绝默许合并 | 只对正常输出比较后删除旧代码 |

变形测试规范不是已内置模型评测执行器；\`T01–T16\` 在没有模拟工具调用、实际输出与回执时只能记为未运行或 \`UNKNOWN\`，不能以结构检查的通过冒充行为验收。

## 11. 证据产物与审计最小集

| 审计维度 | 必需标识 | 验证前提 |
|---|---|---|
| 发现范围 | 真实根、发现器版本、排除、错误及限额 | 原始读取范围可定位 |
| 候选身份 | 物理对象、逻辑别名、版本及数据类别 | 目标和消费者同一版本 |
| 风险与许可 | 风险等级、\`G0–G7\`、决策依据 | 高影响门禁有实际证据 |
| 迁移结果 | 旧消费者、新权威、运行兼容及未迁移项 | 被删实体不再承载独有功能 |
| 执行结果 | 操作、原生回执、状态、时间及副作用 | 真实工具动作存在 |
| 验收结论 | 当前版本测试、恢复和残留证明 | 适用回归全部通过 |
| 保全与未决 | 用户数据、审计历史、第三方及 \`HOLD\` | 未知项未被隐去 |

**审计的边界**：形式完备不等于证据真实；文档声明“已复核”不能证明真实调用发生；观察到旧路径不存在不自动证明所有运行消费者已切换。对外结果须区分候选数、准入数、已实施数、已验证数及未决风险，并限定每个计数的作用域。
