# 语义密度优化与结构变换

## 1. 优化目标与不可变约束

本模块定义文档重构的**多目标约束优化**：提高独立规范/证据信息的表达效能，同时维持语义保真、结构可解析、权威唯一及使用者可判读。禁止通过提高字符随机性、减少字数或引入新术语获得虚假的优化收益。

`Maximize Utility = f(SemanticCoverage, AuthorityCoherence, Auditability, Readability, MaintenanceCost)`

必要约束为 `UnjustifiedRemoval=0 ∧ UnauthorizedRule=0 ∧ BrokenReference=0 ∧ UnresolvedCriticalConflict=0`；`SemanticCoverage` 的完整性必须根据实际来源域和人工复核确定，不宣称统计器能证明自然语言完全等价。

| 指标 | 统计对象 | 可支持结论 | 无法支持 |
|---|---|---|---|
| 字符变化率 | 有效旧/新字符差异 | 实际长度变化 | 语义质量 |
| 原子映射率 | 已审定源原子与目标对应 | 审计记录覆盖比例 | 未发现原子的不存在 |
| 删除证据率 | 合法删项与证据定位 | 删项归源完整度 | 证据本身真实性 |
| 权威重复数 | 同义竞争定义及消费者 | 定义收敛程度 | 任意内容可删除 |
| 结构缺陷数 | 文件、围栏、标题、表格、链接 | 脚本覆盖结构缺陷 | 未实现 Markdown 方言 |
| 判定可执行率 | 有准入、违例及恢复的硬规则 | 文本规范操作性 | 实际工具已可执行 |
| 版本新鲜度 | 证据和目标 SHA-256 一致性 | 验收对应版本 | 验收方法正确性 |

分母为零的指标显示不适用；缺失实际观测不得填入猜测的通过率。

## 2. 规范变换演算

| 操作 | 语义准入条件 | 禁止变化 | 最小复验 |
|---|---|---|---|
| `DELETE_DUPLICATE` | 相同主体、前提、效力及目标的权威条款已保留 | 删除独有例外或不同责任 | 等价映射与消费者引用 |
| `DELETE_OBSOLETE` | 已证实失效且不存在仍有效的迁移/审计义务 | 依据名称陈旧推断无效 | 保留政策及版本证据 |
| `MERGE` | 多个原子合并后仍可单独定位 | 不同义务、等级和作用域被抹平 | 正向及反向覆盖 |
| `SPLIT` | 原条款含多项可独立失败的义务 | 加入原文不存在的顺序 | 依赖关系不变量 |
| `MOVE` | 标题继承、链接与局部生效域仍成立 | 作用域因层级变化而扩大 | 目标结构与入链 |
| `RENAME` | 权威词典确认同义别名及消费者 | API/路径/枚举被静默改名 | 调用者与引用检查 |
| `EXTRACT` | 共用概念具唯一真实权威 | 形成循环依赖或新权限 | 定义与消费者映射 |
| `INLINE` | 一次性抽象没有外部消费责任 | 消除具有复用价值的接口 | 消费者及版本一致性 |
| `PARAMETERIZE` | 参数是已存在的变化维度，取值域明确 | 引入魔术默认或改变范围 | 边界和缺失参数处理 |
| `REPHRASE` | 双向义务与条件等价 | 量词、否定、阈值或承诺强度漂移 | 双向反例 |
| `FORMAT` | 目标解析方言与字面保护已知 | 代码、数据或渲染语义变化 | 结构与方言验证 |
| `REJECT` | 关键源、权限或事实不可判定 | 连带拒绝可独立完成的部分 | 阻断范围一致性 |

所有删除、合并和更名须记录源定位、目标定位、变更理由和最小相关测试；数据清理与资产物理删除另受对应授权门禁约束。

## 3. 权威重组顺序

1. 识别当前文档组的**规范域与职责所有者**，建立现有依赖及真正可见的消费者。
2. 冻结源原子、数值与义务强度，分离可操作条款、事实说明及保留锚点。
3. 消除同义竞争权威，统一引用至唯一来源；不得将原本不同权限层级合并。
4. 以领域、权威、输入、状态、变换、验证和恢复的上位分类构造章节。
5. 仅删除具有等价或失效依据的内容；保留独立例外、负面验证及必要说明。
6. 收敛术语与句法，优先使用“主体—条件—动作—后果—证据”的规范表达。
7. 审查实际 Markdown 方言和全部受影响相对引用；执行相关机器检查及独立语义复核。
8. 在不减少独立义务与可判读性时继续压缩；否则停止，登记无法进一步合并的证据。

源文件用户强调语气可以被转译为有效义务强度；原话只作为来源事实留在审计材料，不复制为规范正文。新文档中的形式化程度必须服务可判定性，而非增加无实现的理论实体。

## 4. 语义等价的反证条件

对可疑的 `REPHRASE/MERGE/DELETE_DUPLICATE` 应分别检查：存在原命题成立而新命题不成立的输入，以及新命题成立而原命题不成立的输入。任一反例成立则不得宣称等价。

| 维度 | 应保持 | 非法变异 |
|---|---|---|
| 主体及职责 | 原负责者与执行边界 | 人工责任转成未实现自动任务 |
| 义务强度 | 必需、允许、禁止、建议 | 许可升级强制 |
| 逻辑关系 | 否定、量词与必要/充分 | 逆命题替换原命题 |
| 数量与时效 | 单位、精度、起点及开闭端点 | 不等号与量纲替换 |
| 条款范围 | 目录、版本、用户集合和例外 | 局部规范扩张为全局 |
| 失败处置 | 与原合同一致的实际后果 | 文档拒绝替换成物理删除 |
| 保留锚点 | 逐字或含义保留的明确要求 | 因缺机器动作而删除 |
| 权威性质 | 来源指令、条件、引用或数据 | 外部引用文本提升为授权 |

若发现新增行为是原需求明确授权的修复，应单独登记 `approved_delta`，不把它计入等价重构。

## 5. 结构选择与层次边界

| 语义关系 | 首选表示 | 无效简化 |
|---|---|---|
| 单项规则 | 明确的规范句 | 重复强调词 |
| 同构规则集 | ID、判定、失败、恢复的对应表 | 合并不同效力条款 |
| 责任或权威层级 | 模块从属及单一词典 | 无依据并列竞争定义 |
| 条件分支 | 互斥优先级清楚的决策表 | 无优先级的重叠分支 |
| 状态迁移 | 有守卫条件的状态表 | 只描述理想路径 |
| 量化边界 | 定义域、单位、精度及区间 | 自拟阈值填空 |
| 语义锚点 | 真实源引文及定位 | 裁切或任意润色 |
| 大规模文档 | 主入口加独立权威参考 | 复制整套规则到每一模块 |

## 6. 规模化治理与停止条件

大型输入依据真实标题、代码围栏、权威域及版本分批，汇总时核对全量文件清单、跨文件引用、术语和保留条件。未取得尾部或外部依赖时，限制覆盖声明；不能用窗口限制反向推定源已完整。

**终止判据**：继续变换将造成独立信息流失、授权边界模糊、阅读分歧或额外维护责任，且无法由可验证收益抵消时结束；不以达到固定字符目标或机械循环次数作为通过标准。
