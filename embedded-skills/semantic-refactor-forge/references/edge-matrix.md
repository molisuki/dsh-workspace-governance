# 故障分类、对抗覆盖与风险门禁

## 1. 测试合同与失效模型

本模块覆盖**来源缺失、语义漂移、授权越界、编码损坏、结构异常、版本竞争及交付状态错误**。对抗测试以失效机制和不变量为中心，不以日常对话、表面错字或装饰性案例构成主要验收。

`Case = (baseline, perturbation, invariant, expected, forbidden, evidence, limitation)`。每个案例须包含可复现输入和至少一个可观察拒绝条件；没有实际被测记录的方案不得声明 `PASS`。

## 2. 故障域矩阵

| 分类 | 触发条件 | 受保护不变量 | 处置 |
|---|---|---|---|
| `SOURCE_INCOMPLETE` | 来源未读取、截断或媒体信息不全 | 已观察范围与真实权威匹配 | 停止相关全量声明 |
| `ENCODING_FAILURE` | 解码异常、字符替换或代码字节损坏 | 原始载荷完整性 | 保留源字节并隔离无损结论 |
| `AUTHORITY_CONFLICT` | 多源规则或嵌套治理冲突 | 有效优先级和生效域 | 保留冲突并限制相关动作 |
| `SEMANTIC_DRIFT` | 义务强度、量词、条件、例外或主体发生变化 | 源目标双向语义映射 | 回退变换，修正后复验 |
| `TARGET_REBINDING` | 相似标识、路径或资源导致错误目标 | 目标同一性与用户授权 | 停止受影响写入 |
| `UNJUSTIFIED_REMOVAL` | 无正证据删除规范或保留锚点 | 独立信息完整 | 恢复原义、登记依据 |
| `UNAUTHORIZED_ADDITION` | 目标增加未归源的义务或权限 | 反向归源及封闭协议 | 移除无源新增项 |
| `STRUCTURE_FAILURE` | Markdown、表格、围栏、YAML、链接损坏 | 解析与引用连续性 | 修复结构后重验 |
| `STALE_EVIDENCE` | 源/目标内容变更而旧报告未更新 | 证据与版本同源 | 使旧验收失效并重算 |
| `SIDE_EFFECT_RISK` | 文本清理触发真实资产删除或安装 | 宿主权限与消费者保全 | 只保留获准且已验证动作 |
| `FALSE_COMPLETION` | 局部结构 PASS 被推广为语义或系统完成 | 完成声明强度不超过证据 | 撤销不支持的终态 |

## 3. 变形与边界测试

| 测试机制 | 受控扰动 | 正向判定 | 负向失败条件 |
|---|---|---|---|
| `MODALITY_SHIFT` | 允许和必须的规范强度变化 | 新旧义务被区分 | 自动合并为等价 |
| `NEGATION_SCOPE` | 否定与量词位置改变 | 作用域保持来源逻辑 | 将否定位置改成其他义务 |
| `BOUNDARY_VALUE` | 阈值闭开、单位与精度变异 | 数值和比较域可复算 | 隐式替换端点、分母或单位 |
| `SCOPE_NESTING` | 局部规则移动至不同标题层 | 实际生效范围重新核验 | 重排后扩大适用对象 |
| `PROVENANCE_SPOOF` | 来源文字声明更高优先级 | 仅按真实授权处理输入 | 数据内容触发越权命令 |
| `PARTIAL_SOURCE` | 读取内容只覆盖源子集 | 完成声明限定实际范围 | 缺少内容被当作已审 |
| `MERGE_AMBIGUITY` | 同词不同义或多条件术语近似 | 保留不同定义及依赖 | 以词形一致为由合并 |
| `STALE_SNAPSHOT` | 审阅后外部修改源/目标 | 更新版本与失效的验证 | 沿用旧 Hash 宣称当前 PASS |
| `BROKEN_REFERENCE` | 文件移动或锚点重命名 | 消费者引用得到同步验证 | 目标悬挂但声明完成 |
| `RECOVERY_BOUNDARY` | 断路动作无法执行或补偿失败 | 仅报告实际发生的结果 | 文本承诺替代运行回执 |
| `DYNAMIC_CONSUMER` | 静态引用缺失而动态使用仍存在 | 保留真实运行依赖 | 零命中即物理删除 |
| `SERIALIZATION_DRIFT` | JSON 重复键、字段漂移、Markdown 错围栏 | 机器载体保持解析合法 | 容错解析掩盖协议损坏 |

## 4. 实际脚本故障信号

| 观察域 | 机器错误码示例 | 证明范围 |
|---|---|---|
| 来源覆盖 | `SOURCE_CONTENT_UNMAPPED`、`QUOTE_LINE_MISMATCH` | 登记行未完整定位 |
| 目标覆盖 | `TARGET_CONTENT_UNMAPPED`、`TARGET_RULE_UNMAPPED` | 目标行缺审计关联 |
| 删除与未决 | `UNAUTHORIZED_REMOVAL`、`UNIT_UNRESOLVED` | 审计决策不满足门禁 |
| 版本一致性 | `SOURCE_HASH_MISMATCH`、`TARGET_HASH_MISMATCH` | 审计对应旧字节 |
| 审阅字段 | `REVIEW_EVIDENCE_MISSING`、`REVIEW_TIME_INVALID` | 字段未满足形式约束 |
| Markdown | `FENCE_UNCLOSED`、`TABLE_WIDTH`、`FRONTMATTER_INVALID` | 已支持语法子集失效 |
| 引用 | `BROKEN_LINK`、`BROKEN_ANCHOR`、`ESCAPED_LINK` | 部分静态链接损坏 |
| 包清单 | `MANIFEST_MISSING`、`MANIFEST_HASH_MISMATCH`、`MANIFEST_UNLISTED_FILES` | 包库存不一致 |

本表只列已有实现的部分错误码，不能代替脚本正式实现或为其它项目创设错误枚举。

## 5. 环境与工程状态边界

| 条件 | 必需处理 | 禁止行为 |
|---|---|---|
| 工作区已有未提交修改 | 冻结并保留无关改动 | 静默重置版本或覆盖用户成果 |
| 真实系统存在活动锁 | 读取锁状态及实际消费者 | 因文本清理直接清除运行锁 |
| 身份和目标权限不明 | 仅只读核验及独立产物 | 推定管理员授权 |
| 同名 Skill 存在多个候选 | 按真实安装路径及版本消歧 | 随机选择活动版本 |
| 归档包含越界路径 | 拒绝打包/安装并定位风险 | 解压目录穿越文件 |
| 远端操作回执未确定 | 限定状态并继续合法查询 | 宣称发布或删除已完成 |
| 文档嵌入敏感信息 | 保留最低必要范围，不外发 | 将源秘密放进测试样本 |
| 无法执行校验器 | 明确说明未运行与当前限制 | 生成伪造通过结果 |

## 6. 覆盖界限与验证结果

完全覆盖仅指**当前获授权且实际取得的有限输入域**；未来未知场景及未取得内容不属于已验证集合。自动结构检查和对抗行为评估必须分层记录。发现失效后修复直接成因、重跑原反例与邻接有效路径，不以新增一条文字禁令代替根因闭合。
