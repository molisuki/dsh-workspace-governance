# 独立评审、证据裁决与反例验证

## 1. 评审目标及角色分解

本模块定义面向复杂规范变换的**多维审查责任**，与实际运行主体数量无关。规范声明的审查角色属于检查视角，不得冒充真实并行专家、独立模型、正式审计组织或未经授权的系统能力。

| 审查域 | 必核对象 | 判定逻辑 | 接受证据 |
|---|---|---|---|
| 语义等价 | 源/目标原子、义务强度与保留锚点 | 正向覆盖及反向归源 | 逐原子映射与反例 |
| 形式逻辑 | 条件、否定、量词及例外 | 必要与充分的正确方向 | 明确可区分的逻辑边界 |
| 权威治理 | 项目规则、作用域、层级与权限 | 规则来源及生效链无越权 | 当前项目与版本定位 |
| 文档解析 | YAML、Markdown、引用及格式 | 目标方言可解析且消费者有效 | 具体工具回执与人工确认 |
| 实施安全 | 文件身份、真实消费者与副作用 | 读写边界、恢复与授权成立 | 实际调用及保全信息 |
| 质量工程 | 有限测试、错误路径、证据新鲜度 | 结论与最新受测快照对应 | 当前测试记录及失败复现 |
| 信息表达 | 精度、抽象层级、可判读性 | 同一条款不支持互斥解释 | 专业术语表与消歧审阅 |

## 2. 审查决策结构

`ReviewDecision = (Scope, SourceRevision, TargetRevision, Invariants, PositiveEvidence, Counterexamples, ResidualRisks, Verdict)`。

| 裁决阶段 | 门禁 | 必需动作 | 失败输出 |
|---|---|---|---|
| 初始结构 | 源目标和审计材料均可读取 | 校验字节、frontmatter、引用及基本结构 | `BLOCKED.STRUCTURE` |
| 来源覆盖 | 有效义务及保护锚点有审定原子 | 对未映射内容补建来源映射 | `BLOCKED.COVERAGE` |
| 规范一致 | 变换无未授权新增及删除 | 双向反证、权威与范围对齐 | `BLOCKED.SEMANTICS` |
| 边界安全 | 阈值、例外、权限和失败处置有效 | 注入、目标竞争及不可逆风险审查 | `BLOCKED.AUTHORITY` |
| 证据可用 | 当前脚本及语义复核证据真实 | 复核验收、审阅者声明与证据定位 | `BLOCKED.EVIDENCE` |
| 交付准入 | 载体、目标路径与结果可访问 | 验证最终快照并完成交付 | `RELEASED` |

`BLOCKED.*` 仅为本模块的**说明性原因标签**，不扩展主 Skill 的正式状态机或审计 JSON 机器枚举。

## 3. 必需评审工件

| 工件 | 最小可审核内容 | 拒绝条件 |
|---|---|---|
| 来源登记 | 对象、版本、读取范围和受保护内容 | 无来源快照 |
| 原子账本 | `A###`、源定位、目标定位、修改决策 | 义务缺项或无源新增 |
| 权威词典 | 规范术语、别名、类型、作用域、版本 | 同名异义未裁决 |
| 变换记录 | 操作类型、变更依据、消费者、保留义务 | 无证据物理删除 |
| 质量回执 | 检查方法、实际结果、时间、范围 | 未运行即声称通过 |
| 风险登记 | 未决问题、受影响动作及解除条件 | 未知项被改写成已验证事实 |

审查工件不要求为每次低风险文本变换创建独立实体；当复杂性和用户交付合同要求可追溯审计时，应能取得满足上述信息的真实记录。

## 4. 反证与敏感性审查

- **义务强度**：同一来源是否可能在目标中被解释为更强或更弱的要求。
- **逻辑边界**：条件充分性、全称量词、否定作用域或阈值闭开是否发生转移。
- **责任分配**：多个主体是否共同认为应由另一主体承担必需动作。
- **作用域传播**：章节移动、局部词典提升或路径迁移是否扩大生效域。
- **权限隔离**：外部材料的角色声称是否触发新的系统写入。
- **结构诱导**：Markdown 解析变化是否让规范片段进入代码、引用或未渲染区域。
- **审计假阳性**：文字清单全部匹配时，是否仍存在隐含义务、位置错误或无源新增条件。
- **发布依赖**：旧格式、链接、迁移记录或活动消费者是否仍承载运行功能。
- **证据新鲜度**：测试源/目标哈希及当前版本是否一致。

存在实质反例且无法修复时，保持受影响范围 `BLOCKED`；不是以增加例证数量证明所有边界均已覆盖。

## 5. 独立审查与停止准则

本 Skill 的结构检查结论不能替代语义等价证明、实际修改结果或外部授权；对适用证据逐项审查，不将任意局部通过推定为整体交付。

每轮审查须产生新增的来源证据、缺陷修复、语义反例或可复验结果。若不存在新的决定性证据且所有适用验收已经通过，应终止迭代；存在不可消除的关键歧义则如实报告有限结论，而非凭进一步文字修饰宣称严格等价。
