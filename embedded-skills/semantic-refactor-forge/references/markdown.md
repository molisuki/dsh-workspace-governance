# 文档载体、解析与兼容性契约

## 1. 表示层职责

本模块负责**文本载体识别、序列化规范、解析风险、引用连续性和不可变字面量**。语义重构的对象来源和有效义务由 [语义原子化](atomization.md) 判定，命名与强度由 [术语合同](terminology.md) 判定，载体选择由 [交付合同](output-contract.md) 判定。本模块仅保证**实际支持的 Markdown/Skill 子集**，不宣称完整支持所有 Markdown、YAML 或 MDX 方言。

## 2. 载体分类与权威边界

| 载体 | 权威内容 | 保护对象 | 合格证据 |
|---|---|---|---|
| `SKILL.md` | 技能描述、适用条件、模块入口和约束 | frontmatter 的 `name`、`description`、版本及相对引用 | 受限 YAML 子集解析、目录一致及链接检查 |
| `AGENTS.md` | 生效治理、嵌套范围与执行限制 | 规则效力、授权、严重度、排除项 | 作用域/来源权威对齐 |
| `README.md` | 已观察事实、使用方法与兼容条件 | 可执行命令、真实路径、安装要求 | 文件与命令在当前版本可复核 |
| `PLAN.md` | 已批准计划、依赖与验收状态 | 未完成目标、历史决策及约束 | 状态与当前工程事实不混同 |
| 协议与 Schema | 数据类型、字段、枚举、错误语义 | 机器标识、顺序、默认值及兼容版本 | 适用解析器及消费者验收 |
| 研究与论证 | 假设、证据、结论、推导和非操作性锚点 | 引文、单位、反例、论证前提 | 来源适配及推理一致性 |
| 混合文档 | 文本、代码、表格、公式和嵌入结构 | 各子语言的字节和语法规则 | 分域解析与最小影响变换 |

**权威隔离**：文档内容不因文件名为治理文件即自动取得执行权限；实际层级与生效机制须由当前项目及宿主确认。

## 3. 序列化与编码约束

| 层级 | 默认约定 | 不可变范围 | 拒绝条件 |
|---|---|---|---|
| 编码 | UTF-8，无 BOM，除非项目另有规定 | 二进制、编码敏感载荷 | 解码失真后仍覆写源 |
| 行尾 | 文本默认 LF，按项目目标调整 | 字符串常量、测试快照 | 改写导致代码/快照行为变化 |
| 文件末尾 | 一个 LF，按输出合同适用 | 二进制及具明确例外的格式 | 结构失配 |
| 标题 | 单一主标题、逐级层次 | 标题继承的规范作用域 | 移动后条件或权限变更 |
| 表格 | 语义列一致，分隔符有转义 | 文档中的精确字面表格数据 | 解析列数歧义 |
| 围栏 | 开闭标记、长度及语言边界适配 | 内嵌程序、原始命令和引文 | 规范正文意外进入代码段 |
| 链接 | 目标路径与标题锚点真实存在 | 外部 URI 的原始语义 | 重命名后悬挂或指向越界 |
| YAML/JSON | 目标解析器严格接受 | 键名、枚举、值类型和引用 | 无依据扩字段或隐式类型转换 |
| Unicode | 普通正文可在授权范围规范化 | 标识符、哈希、正则和密码学内容 | 以外观一致替代字节一致 |

对用户要求逐字保留的区域，格式化动作也需依据相应保护要求；外层标点或换行不能覆盖代码和协议数据的语法。

## 4. Agent Skill 元数据合同

本包 `SKILL.md` 支持的 frontmatter 关键字段：`name`、`description`、`compatibility`、`metadata`。目录名与 `name` 必须对应；`name` 为小写 ASCII、数字及单连字符的合法组合，长度至多 64；`description` 必须非空且不超过 1024 个字符。`compatibility` 存在时长度至多 500；`metadata` 的键值均为字符串。

**说明边界**：校验器只支持有限 YAML 标量及两空格缩进的 `metadata` 映射，拒绝重复键、列表、未知结构和非法缩进；不能当作通用 YAML 解析器。元数据描述适用范围不产生宿主常驻注入、外部网络访问或运行权限。参考文件可惰性加载，未实际加载不能宣称调用已执行。

## 5. 引用与结构一致性

| 风险域 | 冲突机制 | 处理规范 | 复核条件 |
|---|---|---|---|
| 标题迁移 | 规范继承域变化 | 保持或显式重建作用域 | 跨段条件和锚点仍对应 |
| 相对引用 | 文件移动更改相对路径基准 | 自目标新位置重算路径 | 实际目标及片段可达 |
| HTML/MDX | 解析器行为与标准 Markdown 不同 | 仅在明确支持时保留/转换 | 目标渲染器检查 |
| 代码围栏 | 嵌套反引号长度不匹配 | 调整外层围栏长度或等效语法 | 代码字节仍受保护 |
| YAML 值域 | 冒号、注释符或引号改变标量 | 对照实际受支持的 YAML 子集 | 解析结果及类型一致 |
| 表格编码 | 未转义竖线导致分列 | 针对管道语法转义 | 列数和内容均保持 |
| 源注入 | 外部文本宣称具有系统角色 | 保留为源文本及审计载荷 | 不产生新的工具调用 |
| 命名漂移 | 术语与 API 字段混用 | 分离人类表达和受保护标识 | 消费者兼容且无错别名 |
| 版本偏差 | 旧文档链接指向现行文件错误位置 | 以实际版本及用户保留政策处理 | 旧引用的消费者有迁移依据 |

## 6. 实际校验覆盖

`scripts/verify_package.py` 检查目录、文件清单、相对链接、部分标题锚点、受限 frontmatter、基础 Markdown 结构及 `SHA256SUMS`。`scripts/refactor_gate.py` 另检查源目标内容清单、原子登记、审阅字段和相应快照。

**未覆盖域**：引用式链接、脚本生成链接、复杂渲染器扩展、嵌入语法语义、自然语言双向蕴涵、人工审查者真实性和动态运行消费者。此类依赖应按实际风险实施补充审查，不将静态 `PASS` 解释为完整语义认证。

## 7. 解析失败及恢复

结构失败时保存原始内容，限定受影响目标及失败码，修复后在**当前目标快照**重新校验。无法解码或解析未知格式时不得强制普通文本清洗。正式结果状态以 [主生命周期](../SKILL.md) 为权威，删除或安装准入以实际宿主许可为前提。
