# 交付载体、成果状态与版本约束

## 1. 交付层职责

本模块将**已验证的目标规范**映射到用户明确指定的载体，控制文件写入、内联正文、结构化报告、归档及版本迁移的真实结果。内容形成与载体投递是不同事实；只有成果可以访问且对应必要验收成立，才允许声明实际交付。

## 2. 输出载体优先级

| 模式 | 适用输入合同 | 必需交付 | 禁止行为 |
|---|---|---|---|
| `PURE_MARKDOWN` | 明确只允许单一 Markdown 代码块 | 单个有效围栏及完整正文 | 围栏外前后文、未授权元数据 |
| `SUMMARY_PLUS_TEXT` | 同时要求差异摘要与完整文本 | 与真实变更对应的摘要和目标正文 | 摘要替代全文或增加空洞说明 |
| `ARTIFACT` | 明确要求文件、安装包或归档 | 真实存在、内容完整、可访问的产物 | 虚构下载路径与操作回执 |
| `IN_PLACE` | 明确要求修改现有文件 | 授权路径内的真实变更和验证 | 生成平行副本代替原位修改 |
| `REVIEW_ONLY` | 仅要求审计/评估 | 可定位发现、证据、严重度与复验方法 | 未授权写入源文件 |
| `DATA_ONLY` | 仅允许 JSON、CSV 等机器载体 | 严格可解析的数据本体 | 解释、标题或新增字段污染 |

当前用户的最新有效格式要求决定载体；默认模式不得覆盖显式限制。定义模式并不授予额外安装、发布或物理删除权限。

## 3. 文件与归档合同

- **布局**：`SKILL.md` 位于包根目录；当前包保持 `references/`、`scripts/`、`assets/`、`tests/` 的已有真实职责和相对引用。
- **清单**：每个实际包文件由 `SHA256SUMS` 唯一登记，不含运行缓存、未授权秘密或无关临时产物。
- **路径安全**：归档及安装应拒绝绝对路径、父目录穿越、符号链接和非预期覆盖；即使包校验通过，安装仍需宿主工具和目标权限。
- **原位变更**：保留已存在的用户修改，按当前源快照实施，执行后复查完整性；源码更新使旧校验回执失效。
- **来源连续性**：内容删除具正证据且满足保留政策，结构重排不损坏其他消费者和引用。
- **权限区分**：生成文件、打包、复制、安装、部署或外发分别属于不同动作，不能根据前一动作推出后一动作已获授权。

## 4. 生命周期与结果声明

| 状态或事实 | 可支持内容 | 禁止推导 |
|---|---|---|
| `REWRITTEN` | 目标文本已重组 | 语义完全等价 |
| `VERIFIED` | 当前版本指定门禁通过 | 宿主自动执行或所有环境正确 |
| `RELEASED` | 当前产物以指定载体实际交付 | 未观察的安装、部署与可访问性 |
| `BLOCKED` | 特定要求与失败证据已定位 | 整条独立任务均无价值 |
| `MANUAL_ONLY` | 适用的人工审查已声明及定位 | 自动验证脚本实际运行 |
| 机器 `PASS` | 某脚本实现的有限检查通过 | 另一个验证层也自动通过 |

输出报告只描述当前实际状态。必要链接必须确实存在；无独立产物文件时交付真实可承载的正文，明确文件尚未生成。

## 5. 版本演进与兼容迁移

| 变更类型 | 权威要求 | 验收维度 |
|---|---|---|
| 文本等价重构 | 来源保真与现行术语 | 双向规范映射 |
| 已批准语义修正 | 独立变更授权和目标版本 | 新旧合同、消费者及反例 |
| 规则撤销或过期 | 失效证据和法定/项目保留义务 | 依赖与迁移记录 |
| 文件更名或重排 | 所有入链与相对路径对齐 | 文件存在、链接与解析 |
| 协议或枚举修改 | 机器权威及正式兼容迁移 | Schema、解析器和消费者 |
| 同名安装目标 | 目标版本、现有用户内容与覆盖权限 | 无误覆盖及后续可恢复性 |

## 6. 交付验收谓词

`DeliveryValid = FormatCompatible ∧ ArtifactExists ∧ AuthorizedScope ∧ CurrentEvidence ∧ RequiredAcceptancePassed`。

谓词是审查规则，不表示独立的发布或安装自动控制器。复验必须匹配最终字节快照；失败时报告已完成的独立成果及不能宣称完成的范围。
