# Workspace Governance

DSH Desktop 多工作区 Markdown 容量治理插件。采用**文件变更 → 增量复核 → 持久化待办 → 运行中 Agent 建议**。

## 能力

- **容量规则**：文件显式上限 > 最近祖先目录上限 > 工作区默认上限；目录累计预算独立。默认严格计入 Markdown 源文件的全部 Unicode 字符（含空白、换行、代码块）；可显式选择仅统计正文的 `text` 模式，支持规则继承与版本验证。
- **提示模式**：预警、超限、关闭。目标使用率 `max(0,选定触发阈值－精简百分点)`；目标字符数按有效上限向下取整。数值目标不授予删除权限或语义损失许可。
- **监测与任务**：Windows `fs.watch` 配合 450ms 防抖；增量重算变化 Markdown 与祖先容量，目录新增、删除或重命名时完整扫描。只展示包含 Markdown 的目录；空目录不产生容量任务。规则按路径保存，移动或改名后的目录沿新路径继承配置，旧路径规则仍保留以供恢复。无周期全仓扫描；监听失败时延时重挂载并复核。未核验结果不清空已验证待办。
- **Agent 投递**：仅对同工作区处于 `running` 的真实顶层对话使用 `Agent.steer`；不唤醒 `idle` 会话。已交付任务因策略调整、目标实质变化或经完整扫描确认原路径消失时，向原会话定向取消旧任务；新路径与目标仍有效时按最新规则重新投递。当前容量无法复验时标记未知，不复用旧计数。投递回执延迟到策略变更之后仍能补建取消任务，持久化去重；不得取消其他任务。多运行会话独立去重；投递回执持久化，同一会话重启、等长修改、无关策略调整不重复推送；消息被丢弃或有效容量状态改变时允许重试。已明确标记的人工任务消息通过原生收件箱识别并消除二次投递。成功提交不保证模型已读取或采纳。
- **变更日志**：已建立基线后，以 Markdown 内容摘要变化记录新增、修改、删除；字符数可选，等长修改也记录。仅表示文件变化，不推断 Agent 执行或语义保真；历史恢复与快照仍然可用。最近保留 60 条。
- **历史恢复**：已废止插件内重复段落压缩及对应写入接口；仅保留旧快照的哈希/版本校验恢复与日志管理，不自动生成新快照。受保护文档不允许通过恢复接口绕过授权。
- **客户端**：目录、预警、超限、专项、日志五视图；稀疏思维导图支持目录节点锚定式展开/收起：以被点击节点的屏幕位置为基准补偿布局位移，保持缩放与拖拽视图；全局展开、复位、全屏行为不变，根节点保持可视。容量提示、文件变更检测和 Agent Skill 卡片默认收起；检测卡片只读展示待办与投递状态。Skill 支持自定义、内置与关闭，独立于容量提示模式；在完整 Agent 精简提示词下方，取消提示词可按相同 Skill 模式独立展开、编辑、还原与保存。
- **取消提示词**：自定义、内置模式分别持久化完整取消模板，`{{items}}` 为必需的已验证目标明细占位符；旧策略缺少模板时继承内置默认值。Skill 关闭不妨碍已投递旧任务的必要取消，原 Agent 会话、去重和失败恢复逻辑保持独立。
- **Skill 运行时**：任务提示与 Skill 分离；两份完整 Skill 通过 DSH `ctx.skills` 原生注册表按需读取，在 `agent/pre-step` 以 Skill 类型消息加载；检测当前有效会话已装载的 Skill 并复用，压缩后缺失的上下文可重新加载。

## 部署与数据

Desktop Profile 通过 `link:local/dsh-workspace-governance` 注册插件；客户端组件标识为 `workspace-governance`，HTTP 前缀为 `/api/dsh-workspace-governance`。修改源码后重启 DSH 生效。

策略位于 `~/.dsh/state/workspace-governance/`；待办、日志、历史恢复快照分别存放于 DSH 私有状态目录，不写入业务仓库。暂停跟踪保留已有策略。

## 接口与验证

`GET /workspaces`、`/tree`、`/maintenance`、`/remediation`；`PUT /mode`、`/defaults`、`/rules`、`/skill-settings`；`POST /scan`、`/restore`。写接口要求同源、操作请求头与有效性校验。

`node bin/cli.js list|add|check|rules`

`npm test`

## 公开仓库准备

使用 Node.js 24 运行 `npm test`；GitHub Actions 在 Windows 上执行同一测试并检查文件打包清单。构建不需要联网安装额外依赖。

仓库仅包含插件源码、内置 Skill、测试和必要文档。DSH 用户策略、会话、恢复快照和凭据位于仓库之外，禁止上传。HTTP 接口仅允许本机访问，详见 [安全说明](SECURITY.md)。

目前未授予开源许可（`UNLICENSED`），并保留 `private: true` 防止意外发布 npm 包。公开前须由权利人确定许可证，并确认内置 Skill 的再发布权；公开 GitHub 仓库并不自动等同于开源授权。
